# webOwie AI — Subbrand Specification

`webOwie AI` is the official AI/inference/agent subbrand of webOwie.

## Design basis

The system inherits the established webOwie visual language used by the public webOwie site and design resources:

- geometric hexagonal network mark
- core background `#050505`
- core foreground `#F5F5F5`
- signal cyan `#55DCE8`
- compatible cyan `#3DD9E8`
- secondary foreground `#C8CDD2`
- structural grey `#2B3138`
- neutral system/Inter-style sans-serif typography
- high-contrast, infrastructure-oriented layouts

The parent mark is preserved. `AI` is added as a separate cyan module so the product is clearly a subbrand rather than a replacement identity.

## Intended product usage

Use `webOwie AI` for:

- OmniRoute branding
- local and hybrid model routing
- AI gateway surfaces
- agent orchestration
- MCP/ACP infrastructure
- coding agents
- research agents
- marketing automation agents
- OSINT/SOCMINT automation agents

## Naming

Preferred:

- `webOwie AI`
- `webOwie AI Gateway`
- `webOwie AI · OmniRoute`

Do not rename the master brand to `webOwieAI` or visually merge the `AI` letters into the master symbol.

## OmniRoute mapping

Recommended OmniRoute presentation:

- instance name: `webOwie AI Gateway`
- app/favicon asset: `icon-app.svg` or `favicon.svg`
- full header/landing lockup: `logo-horizontal-dark.svg`
- light UI lockup: `logo-horizontal-light.svg`

## Trademark

The webOwie trademark policy remains authoritative. Creating this subbrand does not license the webOwie name, logos or visual identity to third parties.
